# CLAUDE.md — MESA Trainings

The MESA training site (built with [Zensical](https://zensical.org), deployed
to GitHub Pages at <https://idss-mesa.github.io/trainings/>): short,
single-task tutorials for the MESA Portal and its apps.

Follow the repository agent guide in [AGENTS.md](AGENTS.md) — it covers the
OKF v0.2 bundle structure, the required frontmatter (never add `verified:`),
the tutorial rules (drafts stay drafts until a person validates them on the
live portal; public content only; no credentials), and the validation and
generator commands. `site/` is build output — never edit it by hand.
