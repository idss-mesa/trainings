# Explainers

* [What an agent is, and is not](what-an-agent-is.md) - An agent is a language model that calls tools in a loop and chooses its own next step; this page sets it beside a chat model and a fixed pipeline.
* [How an agent reaches data: tools and MCP](tools-and-mcp.md) - An AI agent can only do what its tools let it do, and MCP is the common way those tools are offered to it; this page names the tool servers in the MESA apps.
* [Recalled or retrieved](recalled-or-retrieved.md) - A figure in an AI agent's answer either came back from a tool call or came from the model's memory, and only the first can be checked against your data.
* [Reading what an agent did](reading-what-an-agent-did.md) - The record of an AI agent's calls can be read like a lab notebook, and it goes wrong in five recognisable ways, each with a tell.
