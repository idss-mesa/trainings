# Learning pathways

* [New to MESA](new-to-mesa.md) - Sign in, start a notebook, and keep what you make: 3 tutorials to start with, 15 to 25 minutes in all, and more for when you have time.
* [Get ready for a hands-on session](get-ready-for-a-session.md) - Arrive signed in, with an app that starts and the practice data loaded: 4 tutorials to start with, 20 to 25 minutes in all, and more for when you have time.
* [Check a dataset before you trust it](check-a-dataset.md) - Find out what a dataset holds and where it is incomplete or doubtful: 5 tutorials to start with, 25 minutes in all, and more for when you have time.
* [Work in R](work-in-r.md) - Load the practice data in MESA RStudio Geospatial and check its flags: 2 tutorials to start with, 10 to 15 minutes in all, and more for when you have time.
* [Use an AI agent and check what it says](use-an-ai-agent.md) - Test what an AI assistant tells you against the data, then start an agent of your own: 3 tutorials to start with, 20 minutes in all, and more for when you have time.
* [Leave work others can rerun](leave-work-others-can-rerun.md) - Describe your work and leave a notebook that someone else can run again: 2 tutorials to start with, 15 to 20 minutes in all, and more for when you have time.
* [Every tutorial, by pathway point](../pathway.md) - Every MESA tutorial under the five points of the learning pathway, from finding your way around to sharing work others can rerun, with the time each takes.
* [Self-checks](self-checks.md) - Short questions for checking yourself after a tutorial, each with its answer, the likely slips, and how the answer is confirmed against the practice data.
* [Your progress](../progress.md) - Where you are on each learning pathway, kept only in your own browser, with ways to save a copy to a file, bring one back, and clear it.
